# Lab Overview

I built this home lab to put my knowledge into hands-on work, where I use the whole system and go through different situations that could come up during a regular day in IT. I show my steps from setting everything up and downloading what I need, to managing users, troubleshooting problems, and handling different types of tickets that come in.

## Lab Environment

| Component | Setup |
|---|---|
| Host Computer  | Windows 11 Pro |
| Virtualization | Oracle VirtualBox |
| Server VM      | Windows Server 2019 |
| Client VMs     | Windows 10 |
| Domain         | hamza12.com |
| Directory Service | Active Directory Domain Service |

- Build hands-on experience with Windows Server and Active Directory
- Practice managing users, groups, permissions, and accounts
- Troubleshoot common Windows and network issues
- Work through help desk tickets and document how I solved them
